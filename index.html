Time Tracking for Trello

A Power-Up that logs time on cards (30m, 1h 40m, 1d, 1w), board reports with label and author filters, Excel export, and epic time limits. Data stays in Trello — no server required.

Open UI preview

Format

  • 30m, 1h, 1h 40m, 1.5h, 1:40
  • 1d — work day (default 8 hours)
  • 1w — work week (default 5 days)
  • Russian units still work: 30мин, 2ч, 1д, 1нед

Epics

An epic is a normal card with a checklist of child cards. Set a limit (e.g. 2w). Remaining = limit minus time logged on child cards. Time on the epic card itself does not count toward the limit. Checklist items count only when linked to a card or containing a trello.com/c/... URL.

GitHub Pages

  1. Push this repo to public branch main.
  2. Settings → Pages → Deploy from branch → main → / (root).
  3. Use https://USER.github.io/REPO/ as your site URL.
  4. Create a Power-Up at Trello Power-Up admin. Iframe connector URL: https://USER.github.io/REPO/index.html.
  5. Enable capabilities: Board buttons, Card back section, Card badges, Card detail badges, Card buttons, Show settings, On enable, Authorization status, Show authorization.
  6. Add the Power-Up to a board.

For a repository named USER.github.io, omit REPO from the URL.

API key is optional. Set it in js/config.js if Trello does not return checklist items for epic remaining time in the report.

Storage

Entries are stored in shared Power-Up data on each card (4096 characters per shared card scope). Everyone who can see the card can read the log. The interface allows authors to edit their own entries; shared storage does not enforce per-entry author permissions.
